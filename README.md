# 米柚 MiYou

非官方米游社第三方客户端（HarmonyOS NEXT，ArkTS/ArkUI 原生重写），只读应用，仅用于浏览社区内容。

- 与米哈游（miHoYo）无任何隶属关系；分发不使用「米游社」名称与米哈游素材
- 不收集账号密码：登录在米哈游通行证官方网页内完成或官方扫码通道完成，应用仅保存 Cookie 会话且仅存本机
- 只读：不含发帖、评论、点赞、签到等任何远端写入功能

## 当前状态（v0.8.0）

- 首页信息流：原神 / 星穹铁道 / 绝区零三频道切换，下拉刷新 + 上拉分页 + 去重合并（崩坏3 频道因官方 gids 实测错位已下架）
- 社区搜索：按游戏 + 最热/最新排序 + 游标分页
- 帖子详情：标题/话题/结构化正文（NORMAL delta / PIC / UGC / HTML / JSON 五形态归一为 text/image 块），只读互动数据；新版格式帖经网页客户端身份（x-rpc 四元组 + DS1 签名）解锁，已真机验证
- 评论区：热评游标分页 + 楼中楼可点展开（每楼层独立状态、独立分页、带展开动画）
- 用户主页：资料卡 + 他人帖子列表（自己帖子受官方接口 1001 风控限制）
- 我的：登录身份卡（头像/昵称/UID/简介/四项数据，@Watch 随登录态刷新）+ 沉浸光感开关 + 动态读取的版本号
- 登录：官方网页登录 + 官方扫码登录，Cookie 清洗持久化
- Tab 框架：系统 Tabs 280ms 滑动动画 + 边缘横滑手势 + TabContent 保活不重载 + 点击高光即时同步
- 图片体验：AdaptiveImage 智能比例（16:9 占位 → onComplete 自适应：超细 banner 徽标化、横幅真实比例全显不横裁、表情包小图限高、长图 Cover 到 0.7 下限）；全屏预览 = 单节点一镜到底（单 Image 布局动画往返飞行、终点按图片真实比例的适应矩形、Cover 终点即 Contain、解码门控显影、关闭落位原子卸载，已实测打开/关闭双向无闪烁）+ 捏合缩放 / 双击还原 + 侧滑只关预览
- 动画规范：全站统一 Curve.EaseOut；40/90ms 显影、180ms 布局微调与缩放还原、200~220ms 条件层显隐与飞行、280ms 仅系统 Tabs
