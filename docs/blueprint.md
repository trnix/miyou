## v1.12 变更摘要

- **全局沉浸体验统一**：识别到「首页沉浸、推入页面看似不沉浸」的真实原因为两层：(1) 窗口级沉浸设置在登录/相机/全屏 H5 等流程后可能被系统修改且不会自动恢复；(2) 首页信息流用 `contentEndOffset` 让内容滚到毛玻璃与小白条下面，而帖子详情页内容在小白条上方硬截止，形成非沉浸的观感截断。修复：EntryAbility 沉浸设置提取为独立方法，窗口创建 + 每次返回前台（onForeground）都重新应用；帖子详情页内容列底部避让改为 Scroll 内层内容 padding，内容可滚动穿越透明小白条（与首页信息流观感一致）。
- **R6 搜索实装**：「社区」tab 临时入口，三频道 + 最热/最新排序 + 分页去重 + 竞态隔离；基于上游 TeyvatGuide 确定的 `post/wapi/searchPosts` 端点。
- **正文解析三轮修复**（真机验证通过）：structured_content 字符串形态的 PIC 帖识别（parse-then-detect by keys）；post.content JSON 兜底（用户帖常见形态）；评论 JSON/HTML 图片提取渲染；段落语义修正（Quill 每行一 op 带尾 \n 的拼接 + 空行切分段落）。
- **细节修复**：搜索提交后主动清焦点收键盘；getPostFull 补 `read=1` 参数解决「请升级版本查看」；新版格式帖转为友好引导文案；ArkTS 匿名对象类型语法约束（ExtractedContent 接口）。

## 0. 总原则

1. 蓝图对标官方，实现为纯 ArkTS/ArkUI 干净重写，不使用官方任何代码、bundle 与素材。
2. 只读先行：前期不实现任何远端写入。写功能归 R7 灰度。
3. 防御性实现：接口字段缺失/变动不得导致崩溃。
4. 官方材质 API 启用规则：`uiMaterial.ImmersiveMaterial` 允许使用，必须配能力探测与属性顺序规则（`backgroundColor` 必须写在 `systemMaterial` 之前）。
5. 资产约束：bundleName 固定 `com.miyou.app`；图标为米哈游版权素材、仅限自用不分发。
6. **接口预验原则（v1.7）**：新模块动工前必须以最低成本验证接口可达或拿到可追溯的上游实作源码。
7. **上游证据优先（v1.8）**：以可定位具体文件的上游源码为准；多上游以仍在维护者优先；静态逆向报告只作线索，不作为实现依据。
8. **诊断先行（v1.10）**：涉及风控/签名的接口出错时，先让错误自报家门，再改请求参数；盲改两轮无进展即走诊断构建。
9. **风控识别与止损（v1.11）**：A 域正常、B 域所有认证路径下统一报错（invalid request 类），即可判定为设备指纹风控，客户端侧无解，识别后立即封档止损。
10. **全局沉浸基线（v1.12）**：窗口级沉浸设置必须防御性重复应用（创建时 + 前台恢复），不被中间流程破坏；可视页面的内容滚动必须能穿越安全区边界（contentEndOffset 或内层 padding），不得在透明安全区上方硬截止。

## 3. 视觉与交互规范：沉浸光感玻璃

| 状态 | 视觉效果 | 技术参数 |
|---|---|---|
| 关闭 | 纯色不透明 | REGULAR + interactive=false + 不透明遮罩 |
| 开启（默认） | 厚重光感 | THICK + interactive=true + lightEffect(White) + 0.5vp 半透明白边 |

实现要点：全局沉浸基线防御性应用（创建 + 前台恢复）；双层安全区取最大值 + avoidAreaChange；三层叠加；覆盖容器 `hitTestBehavior(None)`；AppStorage + preferences 持久化；悬浮胶囊底栏；内容滚动必须穿越安全区边界。

## 4. 技术底座需求（含实证）

- 包名 `com.miyou.app`；目标 API 26。
- 网络层版本线：`Endpoints.APP_VERSION=2.117.0`（读接口）；`DsSign.SIGN_VERSION=2.115.0`（DS salt 保留待用）。
- Cookie（实证）：v2 键为主体；bbs 域读接口 ltoken Cookie 即可。
- 设备身份：device_id 首启生成持久化。
- 签名：DS1/DS2 MD5 路线已实装并保留。
- 错误处理：-100/-10001 跳登录；「请升级版本查看」为旧客户端拒绝文案（补 read=1 可规避，残留时为新版格式帖引导官方 App）。
- 渲染：未知块降级；post.content 可能为 HTML 或 JSON 字符串；structured_content 可能为字符串或对象；Quill 段落语义（空行为段落分隔）。
- 消息接口：不投入抓包取证（v1.7）。
