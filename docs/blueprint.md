## v1.11 变更摘要

- **R4（扫码登录）与 R5（战绩/便签/卡片）正式封档**：经真机多轮排查确认，record 域（game_record）对当前账号/设备指纹组合在所有认证路径下均返回 retcode -10001（invalid request），而同一 Cookie 在 bbs 域正常（retcode 0）。具体证据链：
  1. 扫码登录：二维码可生成、官方 App 可识别（b84 头组显示“米游社 PC 登录”，b85 显示“米哈游启动器登录”），但扫码确认后 status 永远停在 Created，查询响应中 tokens/user_info 键虽存在却无实际凭据，多轮头组调整（TeyvatGuide/dsh 双通道、加 Cookie、版本线、通道切换）均无效；
  2. record 域直调：新鲜 ltoken Cookie 直接调 getGameRecordCard（全头/裸请求/DS2(4X) 签名三种头组）均 -10001；
  3. 结论：这不是 Cookie 过期、DS 盐错误、头组不齐或扫码流程 bug，而是**服务器端按设备指纹+账号维度的风控直接拒绝 record 域访问**（bbs 域同 Cookie 正常）。此类风控无法用客户端侧参数绕过，继续投入产出比为零。
- **代码收缩**：删除 `net/QrLoginApi.ets`、`pages/QrLogin.ets`、`net/RecordApi.ets`；MineTab 移除扫码登录按钮、账号探活卡、战绩签名测试卡，回归登录/光感/关于三卡；`main_pages.json` 注销 QrLogin 路由。`DsSign.ets` 保留（实现本身无错，盐与版本线仍在，若未来出现新身份伪装线索可复活）。
- **路线图重排**：M0–R2 + 评论浏览为已完成核心；R4/R5 封档；剩余有价值工作为 R6 只读补全（搜索、用户主页、合集、评论楼中楼、视频播放、版区浏览），全部基于已验证的 bbs 域接口，不依赖 record 域。

## 0. 总原则

1. 蓝图对标官方，实现为纯 ArkTS/ArkUI 干净重写，不使用官方任何代码、bundle 与素材。
2. 只读先行：前期不实现任何远端写入。写功能归 R7 灰度。
3. 防御性实现：接口字段缺失/变动不得导致崩溃。
4. 官方材质 API 启用规则：`uiMaterial.ImmersiveMaterial` 允许使用，必须配能力探测与属性顺序规则。
5. 资产约束：bundleName 固定 `com.miyou.app`；图标为米哈游版权素材、仅限自用不分发。
6. **接口预验原则（v1.7）**：新模块动工前必须以最低成本验证接口可达或拿到可追溯的上游实作源码。
7. **上游证据优先（v1.8–v1.10）**：以可定位具体文件的上游源码为准；多上游以仍在维护者优先；静态逆向报告只作线索，不作为实现依据。
8. **诊断先行（v1.10）**：涉及风控/签名的接口出错时，先让错误自报家门，再改请求参数；盲改两轮无进展即走诊断构建。
9. **风控识别与止损（v1.11）**：同一账号在 A 域正常、B 域所有认证路径下统一报错（且错误码为 invalid request 类），即可判定为服务器端设备指纹风控，客户端侧无解。识别后立即封档止损，不继续消耗迭代轮次。

| 状态 | 视觉效果 | 技术参数 |

## 4. 技术底座需求（含实证）

- 包名 `com.miyou.app`；目标 API 26。
- 网络层版本线：`Endpoints.APP_VERSION=2.117.0`（读接口）；`DsSign.SIGN_VERSION=2.115.0`（DS salt 配套，保留待用）。
- Cookie（实证）：v2 键为主体；bbs 域读接口 ltoken Cookie 即可（retcode 0）；**record 域对当前账号/设备指纹组合统一 -10001，任何 Cookie/DS 组合均无效**（v1.11）。
- 设备身份：device_id 首启生成持久化；record 域风控按 device_fp + 账号维度判定。
- 签名：DS1/DS2 MD5 路线已实装并保留；对 record 域无效（v1.11），对 bbs 域写接口（R7）仍可能有用。
- 错误处理：-100/-10001 跳登录；1034 限流退避。
- 渲染：未知块降级；post.content 可能为 HTML。
- 消息接口：不投入抓包取证（v1.7）。

## 6. 风险与边界

- 接口时效：渲染层兜底 + 版本/salt 集中配置化。
- 接口可达性前置验证（v1.7）。
- 上游时效差（v1.9）。
- 静态逆向报告边界（v1.10）。
- **设备指纹风控（v1.11）**：record 域按设备指纹+账号维度拒绝访问，客户端参数无法绕过；识别特征为「A 域正常、B 域全路径统一 invalid request」。
- 合规：非官方、仅查看授权数据、不接触账密；Cookie 仅存本机；图标为米哈游版权素材、仅限自用不分发。
- 签名资产：7 个 Actions 变量为唯一签名链路来源，任何重构不得输出其明文。
